## Репозиторий
`vmfoberon-star/vmfoberon-star.github.io`:
- ветка `main` — опубликованный сайт;
- ветка `src` — исходники.

Рабочая схема — два клона рядом:
```
git clone -b src  https://github.com/vmfoberon-star/vmfoberon-star.github.io travel
git clone -b main https://github.com/vmfoberon-star/vmfoberon-star.github.io vmfoberon-star.github.io
```

Сборка и публикация:
```
cd travel
python3 build.py                 # весь сайт в site/ (долго, несколько минут)
python3 israel/build_israel.py   # только «Наш Израиль», быстро
rm -rf site/family               # семейный сайт не перезаписывать!
cd ../vmfoberon-star.github.io && git pull --rebase origin main
cp -a ../travel/site/. ./        # или только: cp -a ../travel/site/israel/. ./israel/
git add -A && git commit && git push origin main
cd ../travel && git add -A && git commit && git push origin src
```

Коммиты заканчивать строками атрибуции из системной подсказки чата. Файл `family/private.enc` (216 МБ) внесён в `.gitignore`, его не коммитить.

## Где что лежит (ветка src)
- `data.py` — поездки по миру. Записи `TRIPS` имеют вид `(slug, code, title, place, year, playlist, cover, eps[(yt_id, title, 'm:ss')])`. Миниатюры роликов хранятся в `imgs.json['eps'][yt_id]` как data:URI, запасного варианта с ytimg нет. Английские переводы — в `en/tr_auto.py`.
- `tools/update_eps.py` — еженедельное добавление новых серий с YouTube, подробности в `README_UPDATE.md`.
- `israel/data_il.py` — «Наш Израиль». Записи `TRIPS` имеют вид `dict(id, r, t, p, y, s, lat, lon, ci, hero, b, v=[(yt, title)])`. Регионы: `jer`, `ta`, `north`, `center`, `south`, `guests`. Ещё там есть `CONCERTS`.
  - Фото: `israel/photos/<id>/NN.webp` (1600 px) и `t_NN.webp` (640 px).
  - Подписи: `israel/gal/<id>.txt`, по строке `NN|подпись`.
- `tools/proc_photos.py` — подготовка фото:
  - `sheet <id> <папки>` — контактный лист с номерами;
  - `pick <id> 0,3,5` — делает webp выбранных кадров.
